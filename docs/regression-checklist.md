# 릴리스 전 수동 점검표

자동 테스트가 잡지 못하는 입력·표시 문제를 릴리스 전에 손으로 확인하는 목록이다. 한 번 도는 데 10분 정도 걸린다. #1~#4는 한글 IME 조합 처리(조합 중 Enter에 마지막 글자가 빠지거나 두 번 가는 문제)를 확인한다. Windows 네이티브와 한글 입력은 mygdeck이 내세우는 강점이라 매번 돈다.

준비: 릴리스 빌드(`npx tauri build --no-bundle`)를 Windows 11, 한글 입력기(Microsoft 입력기)에서 실행한다. 프로젝트 둘을 연다. 하나는 Claude Code, 하나는 셸 명령 프로젝트(`"command": "cmd.exe"`)로 하면 사용량을 아낄 수 있다.

## 한글 입력

| # | 할 일 | 기대 결과 |
|---|---|---|
| 1 | 입력창에서 "안녕하세요"를 치다가 마지막 글자 조합 중에 Enter | 조합이 끝난 뒤 한 번만 전송된다. 마지막 글자가 빠지거나 두 번 가지 않는다 |
| 2 | CLI 화면(`Ctrl+.`)에서 한글 입력 | 조합 중인 글자가 커서 위치에 보이고, 확정된 글자가 CLI에 그대로 들어간다 |
| 3 | 한글 입력 상태에서 `Ctrl+1`, `Ctrl+Space`, `Ctrl+P` | 영문 상태와 똑같이 동작한다 |
| 4 | 입력창에서 Shift+Enter로 여러 줄을 쓰고 전송 | 줄바꿈이 유지된 한 번의 입력으로 에이전트에 간다 |

## 붙여넣기와 끌어다 놓기

| # | 할 일 | 기대 결과 |
|---|---|---|
| 5 | 캡처 도구로 찍은 이미지를 입력창에 `Ctrl+V` | 썸네일이 뜨고 이미지 경로가 입력창에 들어간다 |
| 6 | 파일 탐색기의 파일을 입력창으로 끌어다 놓기 | `@경로`가 들어간다 |
| 7 | 셸 터미널에서 에러 줄을 마우스로 선택하고 `Ctrl+I` | 입력창에 코드 블록으로 들어간다 |
| 8 | 코드 뷰어에서 몇 줄 선택하고 `Ctrl+I` | `@파일 L시작-끝`이 들어간다 |

## 세션 유지

| # | 할 일 | 기대 결과 |
|---|---|---|
| 9 | 에이전트가 작업 중일 때 창을 닫고 10초 뒤 다시 열기 | 카드가 "다시 연결됨" 또는 작업 상태로 이어지고, 이전 출력이 보이며 입력이 된다 |
| 10 | 창이 닫힌 동안 `mygdeck-cli status`, `mygdeck-cli send <프로젝트> "echo hi"` | 상태 표가 나오고, 다시 연 창에 보낸 명령이 보인다 |
| 11 | 카드를 `Ctrl+F4`로 닫고 `mygdeck-cli status` | 그 프로젝트 세션이 목록에서 사라진다 |
| 12 | `mygdeck-cli daemon stop` 뒤 덱 열기 | Claude Code 카드가 마지막 대화로 다시 열린다(`--continue`) |

## 알림과 GUI 화면

| # | 할 일 | 기대 결과 |
|---|---|---|
| 13 | 에이전트에 일을 시키고 다른 앱으로 전환 | 끝나면 Windows 알림과 작업 표시줄 깜빡임. 덱으로 돌아오면 그 카드로 이동한다 |
| 14 | 승인이 필요한 명령을 시키기 | GUI 화면에 허용·거부 버튼과 실행될 명령이 보인다 |
| 15 | 에이전트가 "1. … 2. … 어느 쪽으로 할까요?"로 답하게 하기 | 선택지 버튼이 뜨고, 누르면 "1번으로 진행해줘"가 전송된다 |
| 16 | 파일을 고치게 한 뒤 헤더 보기 | `+N −M` 배지가 뜨고, 누르면 변경 파일 목록이 열린다 |
| 17 | 에이전트 메뉴의 `⑂ worktree로 하나 더 열기` | `<저장소>-wt2` 카드가 새로 생기고 에이전트가 시작된다 |
